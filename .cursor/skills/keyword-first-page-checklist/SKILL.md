# Keyword → First Page Checklist

สกิลนี้ใช้เมื่อต้องการ**ดันกลุ่มคีย์ที่ตรงบริการ**ให้ขึ้นหน้า 1 ไม่ใช่ยัดคีย์ทีละคำบนหลายหน้าบาง

อ่านร่วมกับ:
- `.cursor/skills/content-seo-aeo-geo/SKILL.md` — สำนวนและโครงเนื้อหา
- `.cursor/skills/ai-overview-citation/SKILL.md` — entity + FAQ quote-ready
- `.cursor/rules/aio-article-rigger.mdc` — บทความใหม่ต้องส่งโครงร่างก่อนลงเว็บ

---

## หลักการเหล็ก (อย่าข้าม)

1. **หนึ่ง intent หลัก = หนึ่งหน้าเงิน (money page)**  
   คีย์ความหมายเดียวกัน/ใกล้กันอยู่หน้าเดียว — อย่าแตกหน้าซ้ำแย่งกันเอง
2. **หน้าแรกไม่ใช่ถังทุกคีย์**  
   `/` เก็บทางเข้าแบรนด์ + ข้อเสนอหลักของตอนนั้นเท่านั้น (เช่น Ads)  
   บริการเฉพาะ → `/services/...`
3. **Informational ≠ Commercial**  
   `คืออะไร / ทำอย่างไร` → blog  
   `รับทำ / ราคา / เอเยนซี่ / บริษัท` → หน้าบริการ
4. **มี impression แต่ CTR 0 ที่ตำแหน่ง ≤10 = แก้ snippet ก่อน**  
   อย่ารีบเขียนหน้าใหม่
5. **มี impression ที่ตำแหน่ง >20 = ต้องเนื้อหา + ลิงก์ภายใน + ความชัดของ intent**  
   ไม่ใช่แค่สลับ title
6. **ห้ามรับประกันอันดับ 1** ใน copy — วัดจาก impression / click / ตำแหน่งเฉลี่ยใน GSC

## Workflow ทุกครั้ง (คัดลอกเช็คลิสต์ด้านล่าง)

### ขั้น 0 — เก็บข้อมูลฟรี

- [ ] ดึงคีย์จาก **GSC** (28 วัน): query + impressions + clicks + position + หน้า
- [ ] จับคู่คีย์กับบริการจริงบนเว็บ (`/services/seo-phuket`, `/services/local-seo`, `/services/google-ads`, `/services/web-design`, `/services/social-media`, `/pricing`)
- [ ] ตัดคีย์นอกพื้นที่ / แบรนด์อื่น / intent ไม่ตรง
- [ ] (เสริม) Google Autocomplete + SERP คู่แข่ง + Trends เทียบกลุ่มบริการ — ไม่ใช้ volume อย่างเดียวตัดสิน

### ขั้น 1 — สร้างคลัสเตอร์ (หลายคีย์ → กลุ่ม)

จัดคีย์ที่**คนต้องการสิ่งเดียวกัน**ไว้กลุ่มเดียว:

| กลุ่ม | ตัวอย่างคีย์ | หน้าเป้าหมาย |
|---|---|---|
| SEO agency ภูเก็ต | seo agency phuket, seo service phuket, รับทำ seo ภูเก็ต | `/services/seo-phuket` |
| Local SEO / Maps | local seo, รับทำ local seo, google maps seo | `/services/local-seo` |
| Ads | รับยิงแอด ภูเก็ต, รับทำ google ads | `/` หรือ `/services/google-ads` |
| ทำเว็บ | รับทำเว็บไซต์ ภูเก็ต | `/services/web-design` |
| ราคา | seo ราคา, แพ็กเกจ seo | `/pricing` หรือบทความราคา → ลิงก์บริการ |
| เรียนรู้ | local seo คือ, …คืออะไร | `/blog/...` → ลิงก์หน้าบริการ |

ในกลุ่มเดียวเลือก:
- **Primary** 1 คำ (commercial ชัด + volume/impression สูงสุดในกลุ่ม)
- **Secondary** 3–8 คำ (คำพ้อง / long-tail / ภาษาไทย-อังกฤษ)
- **Support questions** สำหรับ FAQ หรือบทความรอง

### ขั้น 2 — เลือกหน้า (ห้ามเดา)

- [ ] เปิด GSC ดูว่า**หน้าไหน**ได้ impression ของคลัสเตอร์นี้อยู่แล้ว
- [ ] ถ้ามีหน้าบริการตรง intent แล้ว → **ใช้หน้านั้น** อย่าสร้างใหม่
- [ ] ถ้าไม่มี → สร้าง/วางแผนหน้าบริการหรือบทความตาม workflow โครงร่าง (aio-article-rigger)
- [ ] ยืนยันหน้านี้ไม่แย่ง intent กับอีกหน้าเงินในคลัสเตอร์ใกล้กัน

### ขั้น 3 — สาขาการลงมือ (เลือกตามตำแหน่ง)

**สาขา CTR (ตำแหน่งเฉลี่ยประมาณ 1–10, คลิกต่ำ)**
- [ ] ใส่ Primary ใน title (ซ้ายสุดถ้าเป็นธรรมชาติ) + จังหวัด/โซนเมื่อเกี่ยว
- [ ] Meta description มีข้อเสนอชัด (ราคาเริ่ม / สิ่งที่ได้ / CTA)
- [ ] H1 ตรงคำถามคนค้น ไม่ยัดคีย์ทุกตัว
- [ ] ย่อหน้าแรกตอบ intent ภายใน ~100 คำ + มี Primary
- [ ] Secondary กระจายใน H2/body/FAQ แบบธรรมชาติ

**สาขาเนื้อหา+โครงสร้าง (ตำแหน่งประมาณ 11–50+)**
- [ ] ครอบคลุม Secondary ทั้งกลุ่มในหน้าเดียว (ตาราง / ลำดับเลข / FAQ)
- [ ] มี section เปรียบเทียบหรือข้อผิดพลาดเมื่อ intent เป็น “เลือกจ้าง / ราคา / ต่างจาก…”
- [ ] Entity โซนภูเก็ตใน body (ป่าตอง กะตะ ตัวเมือง ถลาง กมลา กะทู้ ตามที่เกี่ยว)
- [ ] Internal link: จากหน้าแรก/บริการใกล้เคียง/บทความ related → หน้าเงิน (anchor เป็นภาษาคน)
- [ ] Internal link ออก: ไป pricing / contact / seo-audit / บทความ informational ที่รอง
- [ ] FAQ ≥5 ข้อ ตอบตรงประโยคแรก — รวมคำถามจาก Secondary และ Autocomplete

**สาขา technical ขั้นต่ำ (ทุกหน้าเงิน)**
- [ ] URL สั้น ตรงบริการ ไม่มีพารามิเตอร์ขยะ
- [ ] Canonical ถูกต้อง
- [ ] หนึ่ง H1
- [ ] รูปมี alt ที่มีคีย์หลัก + บริบทภาพ
- [ ] มือถืออ่านได้ CTA ชัด (โทร / LINE / ฟอร์ม)
- [ ] Schema บริการ/บทความตาม skill rich-results ถ้าเป็นหน้าที่รองรับ

### ขั้น 4 — หลายคีย์บนหน้าเดียวทำอย่างไร (ไม่สแปม)

อนุญาต:
- Primary ใน title, H1 (หรือใกล้ H1), intro, 1 H2, 1 FAQ
- Secondary เป็นคำพ้องใน H2/ตาราง/FAQ/body
- คำภาษาไทย + อังกฤษในคลัสเตอร์เดียวกันถ้า intent เดียวกัน

ห้าม:
- ยัด Secondary ทุกตัวลง title
- สร้างหน้าบางสำหรับแต่ละ long-tail ที่ความหมายซ้ำ
- เปลี่ยนหน้าแรกให้กลายเป็นหน้า Local SEO ถ้าข้อเสนอหลักหน้าแรกเป็นคนละบริการ

### ขั้น 5 — วัดผลใน GSC (หลัง deploy 7–28 วัน)

- [ ] Filter ตามหน้าเป้าหมาย
- [ ] ดู Primary + Secondary: impressions, position, CTR, clicks
- [ ] เป้าหมายสั้น: ตำแหน่งดีขึ้น **หรือ** CTR ขึ้นเมื่ออยู่ใน Top 10
- [ ] ถ้า impression ขึ้นแต่คลิกไม่ขึ้น → วนสาขา CTR
- [ ] ถ้าตำแหน่งไม่ขยับ 28 วัน → เสริมบทความ support + ลิงก์ภายใน + ตรวจคู่แข่งหน้า 1

| Cluster | Money page | เหตุผล |
|---|---|---|
| Local SEO commercial | `/services/local-seo` | มีหน้าแล้ว + GSC impression สูง อย่ายิงเข้า `/` |

## Reverse engineering จากคีย์ที่ติด #1 แล้ว (บังคับเทียบก่อนดันคลัสเตอร์ใหม่)

ใช้คีย์ที่**ติดอันดับมือ / SERP จริง**เป็นแม่แบบ — ไม่เดาจากทฤษฎีอย่างเดียว

### คีย์แม่แบบ (อัปเดตมือ 22 ก.ย. 2569)

| คีย์ที่ติด | อันดับมือ | Money page |
|---|---|---|
| รับทำแอด google ภูเก็ต | #1 | `/services/google-ads` |
| รับทำแอด ภูเก็ต | #1 | `/` |
| รับยิงแอด ภูเก็ต | #3 | `/` |
| รับทำ SEO ภูเก็ต | #2 | `/services/seo-phuket` |

### สิ่งที่หน้าชนะทำซ้ำๆ (แพทเทิร์นที่ต้อง copy หลักการ ไม่ copy เนื้อหา)

1. **Primary ภาษาคน + จังหวัด ติดซ้าย title และ H1**  
   ตัวอย่าง: `รับทำ Google Ads ภูเก็ต | …` / H1 เดียวกัน — ไม่ใช้คำกลางอย่าง “บริการ …” อย่างเดียว
2. **Secondary ในคลัสเตอร์เดียวกันถูกถักชัด**  
   title/keywords/FAQ มีคำพ้อง: รับยิงแอด Google, รับยิงแอด Maps, เอเยนซี่ — intent เดียวกันหน้าเดียว
3. **ย่อหน้าเปิด = นิยาม + แบรนด์ + โซน 6 แห่ง + ราคาเริ่ม**  
   ป่าตอง กะตะ ตัวเมือง ถลาง กมลา กะทู้ โผล่ใน answerBlock/intro ไม่ใช่แค่ “ทั่วประเทศ”
4. **ตารางเปรียบเทียบในหน้าเงิน**  
   เช่น Ads vs SEO — ตอบ intent “เลือกอะไร / ต่างกันยังไง”
5. **ข้อผิดพลาดที่พบบ่อย** เป็น bullet ในหน้าบริการ
6. **คลัสเตอร์ลิงก์หนา**  
   หน้าเงิน ↔ บทความราคา/วิธี/industry (≥5–8 ลิงก์ออก) + ลิงก์กลับจาก blog
7. **FAQ ≥7–10** ใช้คำถามจาก Autocomplete/คีย์พ้องเป็นหัวข้อ FAQ โดยตรง
8. **Schema Service** ชื่อบริการ = Primary, `areaServed` = ภูเก็ต (หรือโซนจริง), มีราคา
9. **metadata.keywords** ใส่คลัสเตอร์ไทย commercial (ไม่แทนที่เนื้อหา — เป็นสัญญาณประกอบ)
10. **หน้าแรกกับหน้าบริการแบ่ง intent ชัด**  
    `/` = รับยิงแอด · `/services/google-ads` = รับทำ Google Ads — ไม่ปน Local SEO เข้าหน้า Ads

### เวลาดันคีย์อื่น — เทียบกับแม่แบบก่อนลงมือ

- [ ] Title/H1 มีรูปแบบ `[รับทำ/รับยิง…][บริการ][ภูเก็ต]` เหมือนแม่แบบหรือยัง
- [ ] Intro มีโซน 6 แห่ง + ราคาเริ่ม เหมือนแม่แบบหรือยัง
- [ ] มีตารางเปรียบเทียบหรือบล็อกข้อผิดพลาดหรือยัง
- [ ] FAQ ใช้คำพ้องคีย์เป็นคำถามหรือยัง
- [ ] ลิงก์คลัสเตอร์ blog ↔ บริการ ≥ ระดับหน้า Ads หรือยัง
- [ ] Schema ชื่อบริการ = Primary หรือยัง

ถ้าข้อใด “ยัง” → แก้ข้อนั้นก่อนคาดหวังหน้า 1

## Output ที่ agent ต้องส่งเมื่อรันสกิลนี้

1. ตารางคลัสเตอร์ (Primary / Secondary / หน้า / สาขา)
2. เช็คลิสต์ที่ติ๊กแล้วสำหรับคลัสเตอร์ที่กำลังทำ
3. รายการแก้ไฟล์หรือโครงร่างเนื้อหา (ถ้าเป็นบทความใหม่ → ส่ง outline ตาม aio-article-rigger ก่อนลง repo)
4. เกณฑ์วัดผล GSC หลังลงมือ
