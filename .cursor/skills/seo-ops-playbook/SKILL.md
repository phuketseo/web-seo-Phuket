# PhuketSEO SEO Ops Playbook

**ที่เก็บหลักอยู่ในโฟลเดอร์เว็บ (หาที่นี่ก่อน):**

| ไฟล์ | path |
|---|---|
| สูตร | `seo-ops/FORMULA.md` |
| Log งาน | `seo-ops/LOG.md` |
| อ่านเริ่มต้น | `seo-ops/README.md` |

## บังคับทุกครั้งที่เอเจนต์ทำงาน SEO

1. **อ่าน** `seo-ops/LOG.md` ตอนท้ายๆ ก่อนวางแผนต่อ
2. **ทำตาม** `seo-ops/FORMULA.md` + skill เนื้อหาที่เกี่ยวข้อง
3. **ต่อท้าย** `seo-ops/LOG.md` หลัง deploy หรือเปลี่ยนคีย์/โครงสร้าง
4. อย่าลบประวัติเก่าใน log — เพิ่มได้อย่างเดียว
